# Pre-release format-fixture evidence — 2026-10-03

## Scope

This evidence establishes a committed decoder baseline before the first stable
format freeze. It does not declare the format stable and does not introduce an
internal format version.

## Fixtures

| Fixture | Bytes | SHA-256 | Coverage |
| --- | ---: | --- | --- |
| `database.wsldb` | 94,208 | `eb64a848d5c543a71725ad680df1827a322ee9e425adc44190d4db9dda3d9e52` | Two metadata generations, multi-level branch/leaf tree, inline and overflow values, updates, deletes |
| `buffered.wsldb` | 8,192 | `c030112bcfd0786e69d8792546648dfdebe49795bec6ff3ec8280fa0b953cfc2` | Empty page-tree checkpoint paired with the buffered fixture |
| `buffered.wsldb.wal` | 25,312 | `3fa6b496102f86e97f089147dcd1f1a998848cd4bc5963c03d8c09d2fc75d295` | Consolidated snapshot record followed by two transaction records |

The default test copies the committed bytes to temporary paths, opens them
through the public API, compares every logical entry with an independent
ordered model, and performs full structural verification. It also proves that
the main fixture has at least two tree levels and a reachable overflow chain.

## Determinism check

The opt-in generator wrote all three fixtures to an independent evidence
directory. Byte-for-byte `cmp` and SHA-256 comparison matched the committed
files. Raw regenerated bytes are retained outside the repository under
`wsldb-benchmark-evidence/2026-10-03-format-fixture-determinism`.

The generator is restricted to the Unix atomic-replacement path because the
buffered fixture intentionally contains a consolidated snapshot WAL. Fixture
regeneration is a compatibility decision, not routine test output.

## Remaining release gate

The format is still explicitly unreleased and unversioned. A stable release
requires an explicit freeze decision and a policy plus tested tooling for any
future incompatible migration. Passing these fixtures alone does not close
that gate.
